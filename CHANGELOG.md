# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.1] - 2026-09-20

### Added

- README screenshots of the OK, degraded and syncing states, generated by `tools/shotgen/`.

### Changed

- Sync ETA is now compact (`~12 minutes left`) instead of being elided away.
- State emblem reduced from 45% to 38% of the drive icon.

## [0.3] - 2026-09-20

### Added

- Compact representation, so the widget works in a panel.
- Tooltip listing each member disk and its state.
- RAID level and active/total disk count on the widget face.
- Progress bar, transfer rate and ETA while an array is syncing.
- Status text coloured from the array state.
- French translation, plus `Messages.sh` and `po/`.
- Array picker in the configuration dialog.

### Changed

- The plugin reports a `state` enum instead of an icon name, and all visible strings are built in QML through `i18n()`.
- The configured array is read back on load instead of always using the first one found.
- Property change signals are emitted only when the value changes, not on every tick.
- New dependency: `qml6-module-org-kde-coreaddons`.
- README documents both `plasmoidviewer` invocations.

### Fixed

- No icon was shown unless the array was healthy: Breeze has no `drive-harddisk-updating`, `-warning` or `-error`. An emblem is now overlaid on `drive-harddisk`.
- A rebuilding array was reported as an error, because `sync_action = recover` was not matched.
- An array with a failed member was reported as OK, because only `array_state = degraded` was checked and a real one reports `clean`.
- The configured icon size was discarded by the layout.
- Compiled translations were missing from the `.deb`.
- Packaged files are installed world-readable.

## [0.2] - 2026-01-24

### Added

- `build-deb.sh`, a clean-build script producing a Debian package in `dist/`, with
  version and metadata read from `package/metadata.json`.

### Changed

- Ported the widget to Plasma 6, Qt 6 and KF6.
- Replaced `package/metadata.desktop` with `package/metadata.json`.

### Fixed

- Constrained the status label's width so it no longer resizes the widget to fit
  long array names; the text elides instead.

## [0.1] - 2024-07-27

Initial release, for Plasma 5.

### Added

- RAID array monitoring via `/sys/block/*/md/array_state`, with automatic
  detection of the available arrays.
- Status icon reflecting the array state, and a configurable update interval.
